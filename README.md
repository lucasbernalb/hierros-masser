# Hierros Masser

Sitio web de Hierros Masser (Next.js + Tailwind). `npm install && npm run dev`.
Número de WhatsApp e Instagram: `src/lib/site.ts`.

Nota: `npm run dev` usa webpack (`next dev --webpack`) porque el modo Turbopack por defecto no recargaba los cambios de CSS.
Si los estilos se ven desactualizados: frenar el servidor, borrar la carpeta `.next` y volver a correr `npm run dev`.
